# 🎙️ مغيّر الصوت (Android Voice Changer)

تطبيق أندرويد لتغيير الصوت **لحظياً (Real-time)** أثناء المكالمات وغيرها. يلتقط
صوتك من الميكروفون، يطبّق مؤثرات صوتية، ويعيد تشغيله فوراً عبر مخرج الصوت.

---

## ⚠️ اقرأ هذا أولاً — كيف يعمل مع "المكالمات"؟

لا يستطيع أي تطبيق أندرويد عادي اعتراض صوت **المكالمة الهاتفية عبر الشبكة
(GSM/VoLTE)** وتعديله، لأن صوت المكالمة يُعالَج على مستوى المودم/الهاردوير خارج
متناول التطبيقات (يتطلب صلاحيات root/system أو ROM معدّل). كل تطبيقات "تغيير
الصوت في المكالمات" تعمل بإحدى طريقتين:

1. **مكالمات VoIP خاصة** (واتساب/ديسكورد... التطبيق يملك الصوت).
2. **معالجة الميكروفون + السماعة الخارجية** ← وهي طريقة هذا التطبيق.

**طريقة الاستخدام أثناء مكالمة:**
1. شغّل مغيّر الصوت واختر المؤثر.
2. فعّل مفتاح **"وضع المكالمة"**.
3. ابدأ المكالمة واجعلها على **السماعة الخارجية (Speaker)**.
4. صوتك المعدّل يخرج من السماعة فيلتقطه ميكروفون المكالمة ويسمعه الطرف الآخر.

> ملاحظة: قد تختلف جودة النتيجة بين الأجهزة حسب سياسات توجيه الصوت في كل مصنّع.
> استخدم سماعة أذن سلكية/بلوتوث لتقليل صدى مكبّر الصوت عند الحاجة.

كما يمكن استخدام التطبيق **كوضع تجريبي مستقل** لتغيير صوتك وسماعه فوراً.

---

## ✨ الأصوات والمؤثرات المتوفّرة

**أصوات بشرية:** طبيعي · شاب · رجل · رجل عجوز · فتاة · امرأة · طفل
**أصوات ممتعة:** سنجاب · صوت عميق · وحش · روبوت · فضائي · كهف/صدى · شيطان

مع شريط **"شدة المؤثر"** للتحكّم في قوة التغيير لكل صوت. الأصوات الذكورية تُضاف
لها لمسة دفء (مرشّح تمرير منخفض) لتبدو أكثر طبيعية.

---

## 🧠 كيف تعمل المعالجة (DSP)

- `dsp/PitchShifter.kt` — تغيير طبقة الصوت لحظياً بطريقة **granular delay ذات
  رأسي قراءة** مع نافذة Hann لتفادي الطقطقة (يغيّر الطبقة دون تغيير السرعة).
- `dsp/Effects.kt` — تعديل حلقي (روبوت)، تريمولو (فضائي)، صدى بتغذية راجعة (كهف)،
  ومرشّح تمرير منخفض (تعتيم الصوت).
- `VoiceEngine.kt` — حلقة `AudioRecord → معالجة → AudioTrack` على خيط عالي
  الأولوية، مع تفعيل مانع الصدى (AEC) وكابح الضجيج (NS) عند توفّرهما.
- `VoiceChangerService.kt` — خدمة أمامية (Foreground Service) لإبقاء المعالجة
  تعمل في الخلفية أثناء المكالمة.

## 🛠️ البناء والتشغيل

### الطريقة الأسهل: Android Studio
1. افتح مجلد `android-voice-changer` في Android Studio (Giraffe فأحدث).
2. اترك الاستوديو ينزّل الاعتماديات، ثم شغّل على جهاز/محاكي (Android 7.0 / API 24 فأحدث).

### من سطر الأوامر
```bash
cd android-voice-changer
./gradlew assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```
> يتطلب Android SDK مثبّتاً و`ANDROID_HOME` معرّفاً (أو ملف `local.properties`
> يحتوي `sdk.dir=/مسار/الى/Android/sdk`).

### بناء تلقائي عبر GitHub Actions
يحتوي المستودع على `/.github/workflows/android-build.yml` يبني الـ APK تلقائياً
عند كل دفع ويرفعه كـ Artifact — استخدمه إن لم يكن لديك بيئة أندرويد محلية.

## 🔐 الأذونات

- `RECORD_AUDIO` — التقاط الميكروفون (إلزامي).
- `MODIFY_AUDIO_SETTINGS` — توجيه الصوت/السماعة أثناء وضع المكالمة.
- `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_MICROPHONE` — العمل في الخلفية.
- `POST_NOTIFICATIONS` — إشعار الخدمة الأمامية (أندرويد 13+).

## ⚖️ استخدام مسؤول

الشخصية أو خداع الآخرين؛ قد يكون تسجيل/تعديل المكالمات دون إذن مخالفاً للقانون في
بلدك.
